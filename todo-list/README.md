#Todo List

## Problem

You're given some existing HTML for a Todo List app. Add the following functionality to the app:

- Add new tasks on clicking the "Submit" button.
- The <input> field should be cleared upon successful addition.
- Remove tasks from the Todo List upon clicking the "Delete" button.

## Notes

**Key Topics:** useState, controlled vs uncontrolled components, array map and filter methods, and event handlers.

- Practiced using event handlers (`onClick`, `onSubmit`, `onChange`) and understanding how React passes the event object when the handler is invoked
- Used `event.preventDefault()` in form submissions to prevent page reloads and keep UI state intact
- Gained more confidence working with controlled components by managing input values through React state
- Improved familiarity with `map` and `filter` for adding and removing items from a list
