# GreatFrontend Solutions

This repository contains my solutions to practice problems from [GreatFrontend](https://www.greatfrontend.com/).  
Each problem is organized in its own folder with the relevant component files, CSS, and a README describing my approach and what I learned.

## Goal
The goal of this repository is to practice React fundamentals and strengthen my frontend skills by solving a variety of UI challenges from GreatFrontend.

## Setup Note
This solution focuses on the component logic and styles.
Boilerplate files are omitted since they are provided by the GreatFrontend environment.
